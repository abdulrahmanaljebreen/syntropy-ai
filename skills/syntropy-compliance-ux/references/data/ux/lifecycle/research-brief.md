# Template: Research brief (Discover)

UX's plan for running an accepted research request, written after triage and shared with the requester before fieldwork. Required for anything longer than a heuristic review. Phase: Discover.

## Rules

1. Write it after the request is Accepted, before any recruitment.
   Why: the requester agrees to the plan before time is spent.
2. Start from the FigJam research template (objectives, product overview, method plan), then link the study board in section 1.
   Why: objectives and product overview live there and are reused by the Findings Report.
3. Fieldwork starts only after every sign-off box is checked.
   Why: avoids running the wrong study.
4. Consent and recording handling are decided in the brief, not on the day.
   Why: ethics and PDPL.

## Template

```
# Research brief: [project]

## 1. FigJam study board
Link: [FigJam board, built from the UX Research Templates file]
(Objectives, research question, product overview and method are captured on the board.)

## 2. Logistics
- Recruitment source: (existing users from CRM, panel service, support volunteers)
- Incentive: (if any)
- Tools: (Maze, Useberry, Zoom, Lookback, in person)
- Ethics / consent: how consent is collected and recordings handled

## 3. Timeline
| Milestone | Date |
|---|---|
| Brief approved | |
| Recruitment complete | |
| Fieldwork start | |
| Fieldwork end | |
| Findings readout | |
| Findings report published | |

## 4. Deliverables
- [ ] Findings report in Notion (Research Findings archive)
- [ ] Readout meeting with requester and stakeholders
- [ ] Raw notes / recordings stored in:
- [ ] Tagged for future search: (feature, segment, theme)

## 5. Risks and assumptions
- What could go wrong? (bad recruitment, small sample, wrong method)
- What are we assuming? (users will be honest, prototype is testable)

## Sign-off before fieldwork
- [ ] UX has reviewed
- [ ] Requester has reviewed
- [ ] PM notified (if not the requester)
- [ ] Participants recruited
```

Method durations to plan the timeline: see the methods table in `README.md` (heuristic review 2-4 days up to diary study 4-6 weeks).
